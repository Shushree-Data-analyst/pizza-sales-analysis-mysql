# Pizza Sales Analysis Using MySQL

## Project Title
Pizza Sales Analysis Using MySQL

## Brief Summary
Analyzed pizza sales transaction data using MySQL to uncover revenue trends, customer ordering behavior, product performance, and category-wise sales insights.

## Overview
This project focuses on analyzing pizza sales data using SQL queries ranging from basic to advanced business analysis.

The project includes:
- Data exploration
- Revenue analysis
- Order trend analysis
- Product performance analysis
- Category contribution analysis

## Problem Statement
Restaurants collect large amounts of order data but often lack clear insights into:
- Which pizzas generate the most revenue?
- What sizes are most preferred?
- When are peak ordering hours?
- Which categories perform best?

This project answers these questions using SQL.

## Dataset
Dataset includes:
- Orders
- Order Details
- Pizzas
- Pizza Types

### Main Tables
- `orders`
- `order_details`
- `pizzas`
- `pizza_types`

## SQL Analysis

### Basic Analysis
- Total number of orders
- Total revenue generated
- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizzas

### Intermediate Analysis
- Quantity ordered by pizza category
- Orders distribution by hour
- Category-wise pizza distribution
- Average pizzas ordered per day
- Top 3 pizza types by revenue

### Advanced Analysis
- Revenue contribution percentage by pizza type
- Cumulative revenue over time
- Top 3 revenue-generating pizzas by category

## Key Insights
- Large pizzas were the most frequently ordered size
- Classic category contributed highest sales volume
- Peak order hours occurred during lunch and dinner
- A small number of pizza types generated most revenue

## Sample Business Questions Solved
1. What is the total revenue?
2. Which pizza is most expensive?
3. Which category sells the most?
4. What are peak business hours?
5. Which pizzas drive the most profit?

## How to Run
1. Import dataset into MySQL
2. Open MySQL Workbench
3. Run SQL queries from:

```sql
pizza_sales_queries.sql
```
